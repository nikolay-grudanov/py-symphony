# Handoff Packaging

## Описание
Навык упаковки информации для передачи работы между агентами. Включает структурирование артефактов, контекста и следующих шагов для обеспечения непрерывности работы.

## Когда использовать
- При передаче работы между агентами
- При завершении работы одним агентом и продолжении другим
- При передаче задачи в другую команду
- При создании документации для follow-up

## Когда НЕ использовать
- Для прямой коммуникации без передачи работы
- Для написания документации проекта
- Для создания отчётов

## Входные данные
- Выполненная работа
- Текущее состояние
- Оставшиеся задачи
- Контекст и принятые решения

## Выходные данные
- Handoff package
- Список артефактов
- Контекст для продолжения
- Следующие шаги
- Вопросы для уточнения

## Зависимости
- Нет (базовый навык)

## Режимы отказа
- Неполная информация
- Неясные требования
- Пропущенный контекст
- Неопределённые следующие шаги

## Шаблоны и чек-листы

### Шаблон Handoff Package
```markdown
# Handoff Package

## Work Summary
Выполненная работа за этот период

## Current State
- Status: текущее состояние
- Progress: прогресс в процентах

## Artifacts
| Artifact | Location | Description |
|----------|----------|-------------|
| file1 | path/to/file | description |
| file2 | path/to/file | description |

## Context
### Decisions Made
- Decision 1: обоснование
- Decision 2: обоснование

### Open Questions
- Question 1: что нужно уточнить

## Next Steps
- [ ] Step 1: описание
- [ ] Step 2: описание

## Blockers
- Blocker 1: описание
- Blocker 2: описание

## Notes for Next Agent
Any additional context or warnings
```

### Чек-лист
- [ ] Артефакты включены
- [ ] Контекст понятен
- [ ] Следующие шаги определены

- [ ] Вопросы идентифицированы
- [ ] Блокеры указаны
- [ ] Достаточно для продолжения работы
