# Repo Structure Design

## Описание
Навык проектирования структуры репозитория для программного проекта. Включает определение директорий, файловых конвенций, организации кода и документации.

## Когда использовать
- Создание нового проекта с нуля
- Рефакторинг существующей структуры репозитория
- Миграция на новую структуру
- Определение стандартов для команды

## Когда НЕ использовать
- Для добавления новых файлов в существующую структуру
- Для простых изменений в коде
- Для настройки CI/CD

## Входные данные
- Требования к проекту
- Язык программирования и фреймворки
- Стандарты команды
- Тип проекта (backend, frontend, fullstack, library)

## Выходные данные
- Структура директорий
- Файловые конвенции
- Документация структуры
- Рекомендации по организации кода

## Зависимости
- coding-standards - для согласования стандартов кодирования

## Режимы отказа
- Неудобная структура для разработки
- Проблемы масштабируемости
- Несоответствие стандартам экосистемы
- Путаница в ответственности модулей

## Шаблоны и чек-листы

### Шаблон Structure
```
project-root/
├── .github/           # GitHub workflows
├── docs/             # Документация
├── src/              # Исходный код
│   ├── modules/      # Модули
│   └── main/         # Точка входа
├── tests/            # Тесты
├── configs/          # Конфигурации
├── scripts/          # Скрипты
├── README.md         # Документация проекта
├── LICENSE           # Лицензия
└── .gitignore        # Git ignore правила
```

### Чек-лист
- [ ] Разделение concerns реализовано
- [ ] Масштабируемость учтена
- [ ] Maintainability обеспечен
- [ ] Соответствие стандартам экосистемы
- [ ] CI/CD директории настроены
- [ ] Документация включена
- [ ] Тесты отделены от кода
