# Verification Agent - Навыки (Skills)

## Обзор

Verification Agent использует следующие навыки для эффективной верификации артефактов.

## Навык: Requirements Analysis

### Описание
Способность анализировать требования из ADR и SPEC.md для определения что должно быть верифицировано.

### Компоненты навыка

#### 1. Изучение ADR
- Чтение и понимание ADR
- Извлечение требований
- Понимание архитектурных решений
- Соотнесение с реализацией

#### 2. Изучение SPEC.md
- Чтение соответствующих разделов SPEC.md
- Извлечение требований из SPEC.md
- Понимание constraints

#### 3. Кросс-референсинг
- Сопоставление требований с реализацией
- Проверка что все требования покрыты
- Идентификация missing функциональности

### Best Practices

- Изучать ADR полностью перед верификацией
- Изучить соответствующие разделы SPEC.md
- Создать list всех требований для cross-reference
- Проверять что каждое требование покрыто

## Навык: Code Review

### Описание
Способность проводить детальный code review для проверки quality и соответствия.

### Компоненты навыка

#### 1. Code standards review
- PEP 8 compliance
- Type hints проверка
- Docstrings проверка
- Naming conventions

#### 2. Code quality review
- Clean code principles
- SRP (Single Responsibility Principle)
- DRY (Don't Repeat Yourself)
- Code organization

#### 3. Error handling review
- Error handling implementation
- Custom exceptions
- Error messages
- Logging

#### 4. Security review
- Input validation
- SQL injection prevention
- XSS prevention
- Password handling

### Best Practices

- Проверять code standards compliance
- Проверять code quality principles
- Проверять error handling
- Проверять security best practices

## Навык: Test Coverage Verification

### Описание
Способность верифицировать что тесты покрывают все требуемые scenarios и достигают target coverage.

### Компоненты навыка

#### 1. Unit test verification
- Все public methods протестированы
- Edge cases протестированы
- Error paths протестированы
- Mocking appropriate

#### 2. Integration test verification
- Интеграции с внешними API протестированы
- Database integration tests
- Test data setup/teardown

#### 3. Coverage analysis
- Line coverage
- Branch coverage
- Function coverage
- Uncovered code review

#### 4. Test quality verification
- Tests ясные и понятные
- Tests independent
- Test fixtures appropriate

### Best Practices

- Проверять что все public methods протестированы
- Проверять что edge cases протестированы
- Проверять что target coverage достигнут
- Проверять test quality

## Навык: Documentation Review

### Описание
Способность проверять что документация полная, точная и полезная.

### Компоненты навыка

#### 1. Docstrings review
- Все public functions/classes имеют docstrings
- Docstrings follow standard format
- Args документация полная
- Returns документация полная

#### 2. README review
- Installation instructions ясные
- Usage examples предоставлены
- API documentation links

#### 3. API documentation review
- Autogenerated docs созданы
- Examples для всех методов

### Best Practices

- Проверять что все public functions/classes имеют docstrings
- Проверять что README обновлен
- Проверять что API documentation создана

## Навык: Issue Classification

### Описание
Способность классифицировать findings по severity и priority.

### Компоненты навыка

#### 1. Severity classification
- Critical: Блокирует production deployment, security vulnerability
- High: Существенная функциональность отсутствует или некорректна
- Medium: Незначительная функциональность отсутствует или quality issue
- Low: Minor issue, cosmetic change

#### 2. Impact assessment
- Оценка влияния на систему
- Оценка влияния на пользователей
- Оценка влияния на production

#### 3. Urgency determination
- Immediate fix required
- Fix in next release
- Can be deferred

### Best Practices

- Классифицировать findings по severity
- Оценивать влияние на систему
- Оценивать влияние на пользователей
- Определять urgency

## Навык: Report Generation

### Описание
Способность создавать детальные и понятные отчеты о верификации.

### Компоненты навыка

#### 1. Report structure
- Overview
- Артефакты для верификации
- Валидация (все sections)
- Findings (с классификацией)
- Summary
- Recommendation
- Appendix

#### 2. Clear communication
- Лаконичные и ясные описания
- Использование bullet points и tables
- Evidence для всех findings

#### 3. Actionable recommendations
- Specific suggestions
- Priority order
- Examples где применимо

### Best Practices

- Использовать стандартную структуру отчета
- Документировать все findings с evidence
- Классифицировать findings по severity
- Предоставлять actionable recommendations

## Навык: Cross-Reference Verification

### Описание
Способность проверять соответствие между требованиями и реализацией.

### Компоненты навыка

#### 1. Requirements extraction
- Извлечение требований из ADR
- Извлечение требований из SPEC.md
- Извлечение требований из спецификаций

#### 2. Implementation mapping
- Поиск code для каждого требования
- Проверка что реализация соответствует требованиям
- Идентификация missing функциональности

#### 3. Evidence collection
- Сбор evidence для каждого требования
- Ссылки на code
- Ссылки на tests

### Best Practices

- Извлекать все требования из ADR и SPEC.md
- Маппировать каждое требование на реализацию
- Собирать evidence для каждого требования

## Навык: Automated Checks

### Описание
Способность использовать automated tools для проверки compliance.

### Компоненты навыка

#### 1. Linting
- Запуск linters (flake8, pylint, etc.)
- Проверка PEP 8 compliance
- Проверка style guidelines

#### 2. Type checking
- Запуск type checkers (mypy, etc.)
- Проверка type hints completeness
- Проверка type correctness

#### 3. Security scanning
- Запуск security scanners (bandit, etc.)
- Проверка на security vulnerabilities
- Проверка dependencies на vulnerabilities

#### 4. Coverage analysis
- Запуск coverage tools (pytest-cov, etc.)
- Анализ coverage metrics
- Идентификация uncovered code

### Best Practices

- Запускать automated checks перед manual verification
- Документировать результаты automated checks
- Использовать результаты как baseline для manual verification
- Investigate failures в automated checks
