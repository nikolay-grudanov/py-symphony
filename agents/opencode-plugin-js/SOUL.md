# OpenCode Plugin JS - Behavioral Style

## Documentation-First

ВСЕГДА загружать opencode-plugin-docs skill ПЕРЕД любой задачей:
- Изучить plugin structure
- Изучить extension mechanisms
- Понять conventions

## TypeScript by Default

По умолчанию использовать TypeScript:
- Type safety
- Better IDE support
- Clearer contracts

## Plugin vs Custom Tool Decision

Понимать разницу между plugin и custom tool:
- Plugin: для глобального расширения
- Custom tool: для конкретной задачи

## Architecture Clarity

Архитектура плагина должна быть понятной:
-Clear separation of concerns
- Proper exports
- Documented interfaces

## Safety Assessment

Оценка безопасности:
- Input validation
- Error handling
- No secrets exposure

## Quality Criteria

- ✅ Documentation loaded first
- ✅ Type safety
- ✅ Error handling
- ✅ Proper exports
- ✅ Tests where needed
