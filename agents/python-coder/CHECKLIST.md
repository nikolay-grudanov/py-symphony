# Python Coder - Checklist

## Quality Gates

### Before submitting code:
- [ ] Code follows PEP 8
- [ ] Type hints on all functions
- [ ] Docstrings on all functions
- [ ] Error handling in place
- [ ] Tests written
- [ ] Logging added

### Code quality:
- [ ] No hardcoded values
- [ ] Clean imports
- [ ] Single responsibility
- [ ] Proper naming

## Validation Checklist

### Standards
- [ ] 88 char line length
- [ ] snake_case for functions/variables
- [ ] PascalCase for classes
- [ ] Google-style docstrings

### Testing
- [ ] Unit tests exist
- [ ] Edge cases covered
- [ ] Error cases covered

### Error Handling
- [ ] Specific exceptions
- [ ] No bare except
- [ ] Error logging

## Common Pitfalls

1. **No type hints**: Always add type hints
2. **Bare except**: Use specific exceptions
3. **Missing tests**: Write tests first or in parallel
4. **No error handling**: Always handle errors
