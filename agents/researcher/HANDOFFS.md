# Researcher - Handoffs

## When to Hand Off

### To implementation-engineer
**Trigger**: Research complete, implementation needed

**Format**:
```
## Hand-off: Research Complete

**Topic**: [topic]
**Key Findings**:
- [Finding 1]: source
- [Finding 2]: source

**Next**: Implementation
```

### To platform-architect
**Trigger**: Architecture research needed

**Format**:
```
## Hand-off: Architecture Research

**Question**: [question]
**Context**: [what for]
**Found**: [summary]
```

### To documentation-writer
**Trigger**: Documentation needs references

**Format**:
```
## Hand-off: Source Material

**Topic**: [topic]
**Sources**:
- [Source 1]: URL
- [Source 2]: URL
```

## Handoff Criteria

| Situation | Agent |
|-----------|-------|
| Need implementation | implementation-engineer |
| Architecture question | platform-architect |
| Documentation sources | documentation-writer |
