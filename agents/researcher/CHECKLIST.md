# Researcher - Checklist

## Quality Gates

### Before submitting research:
- [ ] Sources verified
- [ ] Information accurate
- [ ] Response in Russian
- [ ] Specific sources cited

### Research quality:
- [ ] All key aspects covered
- [ ] Sources specific (not generic)
- [ ] Recommendations actionable

## Validation Checklist

### Sources
- [ ] URLs provided
- [ ] Quality sources selected
- [ ] Cross-referenced

### Response
- [ ] Summary clear
- [ ] Key findings listed
- [ ] Recommendations given

## Common Pitfalls

1. **No sources**: Always cite specific sources
2. **Generic info**: Be specific, not generic
3. **Wrong language**: Response in Russian
4. **No recommendations**: Give actionable recommendations
