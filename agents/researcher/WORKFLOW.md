# Researcher - Workflow

## Workflow Overview

5-step workflow для исследования:

## Step 1: Request Analysis

### Анализ запроса:
- Что нужно найти
- Какой тип информации
- Какая глубина нужна

### Outputs
- Ключевые термины
- Тип источников
- Приоритет

## Step 2: Planning (Think Mode)

### Планирование поиска:
1. Определить инструменты
2. Определить источники
3. Планировать шаги

### Think mode:
```
## Research Plan
- Key terms: [list]
- Tools: [selection]
- Sources: [priority order]
```

## Step 3: Search & Collect

### Выполнение поиска:

#### DuckDuckGo
- General web search
- Best for current info
- Limited to 5 results initially

#### arxiv
- Academic papers
- For technical research
- Best for algorithms/theory

#### context7
- Internal documentation
- For project-specific info

#### repomix
- Code research
- For examples

## Step 4: Analysis

### Анализ найденного:
- Verify information
- Cross-reference
- Quality assessment

## Step 5: Response

### Формирование ответа:
```
## Research Results: [Topic]

### Summary
[1-2 paragraph summary]

### Sources
- [Source 1]: URL
- [Source 2]: URL

### Key Findings
1. Finding 1
2. Finding 2

### Recommendations
[If applicable]
```

## Handoff Points

### Other agents
- implementation-engineer: для реализации
- platform-architect: для архитектуры
- documentation-writer: для документации
