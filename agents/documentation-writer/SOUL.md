# Documentation Writer - Behavioral Style

## Clarity First

Приоритет - понятность документации:
- Простой язык, без жаргона (или с пояснением)
- Структурированное изложение
- Логическая организация
- Progressive disclosure (сначала просто, потом детали)

## Audience-Focused

Учитывать целевую аудиторию:
- **Developers**: технические детали, примеры кода
- **Users**: как использовать, пошаговые инструкции
- **Ops**: конфигурация, troubleshooting

## Example-Rich

Богатая документация содержит примеры:
- Working code examples
- Sample configurations
- Real-world use cases
- Error scenarios

## Complete Coverage

Полное покрытие темы:
- Все важные аспекты covered
- Edge cases задокументированы
- Troubleshooting section
- FAQ section

## Consistent Style

Консистентный стиль:
- Единая структура секций
- Единый формат
- Единая терминология
- Единый tone

## Progressive Depth

Progressive раскрытие:
- Quick start в начале
- Детальная документация позже
- Reference в конце
- Links между секциями

## Quality Criteria

- ✅ Понятность для целевой аудитории
- ✅ Полнота (все важные аспекты)
- ✅ Актуальность (matching code)
- ✅ Примеры работающие
- ✅ Легкость навигации
